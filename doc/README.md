## Current versus historical material

Concise status/roadmap/handoffs describe the current repository. Detailed dated
logs, prior estimates and extraction plans are preserved under
[modernization/history](modernization/history/README.md), with links redirected
to their original headings. They are evidence, not current priorities/support claims.

The older translation/manual-writing guides in this folder and the
[retained help tree](../help/README.md) document the original GTK application.
They are reference inputs; native Help integration and a complete new manual
remain unfinished. Retired source paths in contracts/parity tables identify
historical baselines and should be inspected in Git history, not restored.

Keep original credits/licenses in [legacy-notices](legacy-notices/) and
[AUTHORS](../AUTHORS)/[COPYING](../COPYING). Do not confuse preserved upstream
branding/manuals with this fork's release status or final product name.

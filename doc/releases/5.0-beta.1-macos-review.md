The package has Xiphos, map renderer and locale notices. It still needs a
version-matched notice and source set for the native dependencies, including
the exact package-manager patches and build recipes where applicable.

The present SWORD source contains GPLv2-only notices. The shipped curl links
OpenSSL 3 under Apache 2.0. Establish whether a documented exception covers
this combined distribution before publishing. If none applies, test a rebuild
using a compatible TLS dependency configuration and audit its full closure,
including CLucene and the other bundled dependencies.

## URLSession follow-up

The replacement Mac build uses URLSession for core downloads and a SWORD
build without legacy network transports. The Mach-O audit found 18 external
libraries, down from 28. It found no linked curl, OpenSSL, or GnuTLS libraries
and measured a macOS 27.0 floor. ICU and CLucene remain in this local build.
The native dependency notices and matching source review still applies to
the replacement bundle.

The source-material archive maps all 18 URLSession bundle libraries to
versioned source archives and includes the native notices and build recipes.
The GLib bottle checksum matches Homebrew core commit
[68093a0](https://github.com/Homebrew/homebrew-core/commit/68093a0680c21eb19fb034af0d8c5104848315e7).
The bottle's embedded formula matches the installed copy. The historical
patch matches at the bottle's build and publication dates. The seven
MacPorts Portfiles match the copies embedded in their binary archives.

For the remaining license review, CLucene Core offers an LGPL 2.1 option.
Confirm its application to both shipped CLucene libraries and their compiled
subcomponents. The source archive includes the upstream notices and both
license texts.

The repackaged tester ZIP includes the collected native notices and the
library-to-source manifest. The app and its nested binaries passed strict
ad-hoc signature verification after repackaging. The source and binary
archives have separate SHA-256 checksums.

The binary audit found `clucene-core` and `clucene-shared` in the closure.
It did not find the CLucene contributions library. The UTF-8 routines
exported by `clucene-shared` carry an LGPL grant in their source header.
The source set includes CLucene's subcomponent notices.

# Xiphos 5.0 beta 1

This beta introduces the native Mac reader and the GTK4 Linux preview,
both using the shared SWORD-based core.

- Compare translations, search passages and look up available word and lemma data.
- Use bookmarks, notes and personal study modules.
- Open biblical maps with optional offline regional packs.
- Export passages as text or HTML. On Mac, formatted printing is the default,
  with a separate plain-text option.

This is a beta. Back up your Xiphos profile and personal modules before testing
an upgrade. Linux packages target Fedora 45 ARM64 and Debian 13 x86-64.
